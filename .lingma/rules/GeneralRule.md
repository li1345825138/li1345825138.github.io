生成代码时始终遵循以下规则：

1. **输出语言**：所有用户可见的输出（例如 `print`、`console.log`、错误信息、日志、提示等）必须使用英文。
2. **注释**：所有注释——包括文件头、函数文档字符串、行内注释和 TODO——必须用英文编写。
3. **代码格式**：严格遵守目标编程语言的官方或社区标准格式规范（例如 Python 遵循 PEP 8，Java 遵循 Google Java Style 等），保持一致的缩进、空格和命名规范。
4. **API 准确性**：在编写依赖外部 API、库或框架的代码前，**必须调用 `context7` MCP** 获取最新、准确的 API 签名和使用方式。禁止猜测或虚构 API 细节。
5. **任务拆解**：对于任何非简单请求，**必须调用 `sequentialthinking` MCP** 将任务分解为逻辑清晰的子步骤。只有在完整计划确认无误后，才生成代码。
6. **不确定性处理**：若需求存在任何模糊之处（例如目标语言、预期副作用、运行环境等），**必须先向用户提问澄清**，不得擅自假设。
