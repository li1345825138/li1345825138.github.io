## 项目概述

这是一个 Windows 系统管理和激活脚本仓库，包含以下 PowerShell 脚本：
- 使用产品密钥激活 Windows
- 驱动程序管理和安装
- Office 许可证管理
- 系统配置和实用工具

这些脚本设计为以管理员权限运行，提供各种 Windows 管理功能。

## Architecture

### 核心脚本
- `act`, `office`, `pro`, `pro1`, `apple`, `driver` - 专门脚本，解码并执行远程 PowerShell 代码

### 主要功能
- 产品密钥验证和格式化
- 为批量许可配置的 KMS 服务器
- 时间同步以进行激活
- 多种激活方法（基于密钥、在线激活）
- 错误处理和重试逻辑
- 重置和清理功能

## Common Development Tasks

### 构建/测试脚本
由于这些是 PowerShell 脚本，测试包括：
1. 以管理员权限在 PowerShell 中运行脚本
2. 使用 `PowerShell -Command "Get-Content script.ps1 | Test-ScriptFileInfo"` 验证语法
3. 在适当的 Windows 系统上测试激活功能

### 添加新脚本
1. 创建新的 `.ps1` 文件，遵循现有命名约定
2. 实现所需函数并正确处理错误
3. 添加遵循现有模式的文档注释
4. 在提交前测试功能

### 修改现有脚本
- 始终维护与现有功能的向后兼容性
- 在进行重大更改时更新版本号和变更日志
- 尽可能保留现有的变量名和函数签名

## 文件结构指南

- **激活脚本**：处理 Windows/Office 产品密钥激活
- **管理脚本**：处理驱动程序安装、系统配置
- **实用工具脚本**：提供辅助函数和常见操作

## 安全考虑

⚠️ **重要**：这些脚本修改关键系统设置并需要管理员权限。始终：
- 执行前验证脚本来源
- 仔细审查代码更改
- 尽可能在隔离环境中测试
- 记录对安全敏感操作的任何修改

## Git 工作流程

- 使用中文描述性提交信息（遵循现有模式）
- 以功能区域为前缀：`feat(activation)`、`refactor(config)`、`fix(error-handling)`
- 保持脚本更新为最新的 Windows 激活方法

## 故障排除

常见问题及解决方案：
- **权限被拒绝**：以管理员身份运行 PowerShell
- **激活失败**：检查网络连接和 KMS 服务器可用性
- **脚本错误**：验证 PowerShell 执行策略设置
- **密钥格式问题**：使用脚本内置的密钥格式化逻辑
